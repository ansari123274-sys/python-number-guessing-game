# 🎮 Number Guessing Game

## About

This is a simple number guessing game built using Python.

## Features

* Random number generation
* Limited attempts
* Too High and Too Low hints
* Win or lose message

## Technologies Used

* Python
* Random module

## How to Run

Run the following command in the terminal:

```bash
python number_guessing_game.py
```
